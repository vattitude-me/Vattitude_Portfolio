PWA Installation & Git Deployment Guide

Install PulseDesk as a native-like app on macOS & Windows PC

Why a single-file PWA? PulseDesk embeds its own Web Worker timer, Web Audio synthesizer, and Web App Manifest inside a single index.html file—zero build steps or external dependencies required.

Step 1: Push to your Git Repository & Enable GitHub Pages

Click the "Download index.html" button in the top bar, then run these commands in your terminal:

mkdir pulsedek-pwa && cd pulsedek-pwa
mv ~/Downloads/index.html ./index.html
git init
git add index.html
git commit -m "Initial commit: PulseDesk Reminder PWA"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/pulsedesk-pwa.git
git push -u origin main

Step 2: Install on Mac or Windows PC

  • Via GitHub Pages / Vercel / Netlify (Recommended): Enable GitHub Pages in your repository settings (Settings → Pages → Deploy from main branch). Open your live HTTPS URL in Chrome, Edge, Brave, or Safari (macOS Sonoma+) and click the Install App icon in the address bar (or File → Add to Dock on Safari).
  • Via Localhost: Run npx serve . or python3 -m http.server 8080 in the folder and open http://localhost:8080 to install immediately without hosting online.

Step 3: Background Reliability Tips

PulseDesk uses a dedicated Blob Web Worker thread so Chrome/Edge/Safari tab throttling won't freeze your countdown when minimized. Make sure your OS "Do Not Disturb / Focus Mode" allows notifications from your browser.
